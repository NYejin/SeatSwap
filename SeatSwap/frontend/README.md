# SeatSwap Frontend (React + TypeScript + Vite)

## 폴더 구조
- api         — axios 클라이언트 (client.ts에서 JWT 인터셉터 일괄 처리)
- components  — 공용 컴포넌트 (ProtectedRoute, TextField 등)
- pages       — 라우트 단위 화면 (App.tsx 라우팅 참고)
- types       — 백엔드 DTO에 대응하는 타입
- hooks       — useAuth 등 커스텀 훅

## 현재 상태
- 구현됨: 로그인(`/login`)·회원가입(`/signup`), 공연 목록(`/`), 공연 등록(`/performances/new`), 공연 상세(`/performances/:id`), 마이페이지(`/me`). 로그인이 필요한 화면은 ProtectedRoute로 보호하고, api/client.ts에서 401 재발급 인터셉터를 처리한다.
- 교환 화면(2026-10-08, `feature/exchange-ui`, 미커밋; 좌석표는 쓰지 않고 구역·열·번 텍스트 입력, 구역 자동완성 없음):
  - `/tickets/new` 티켓 등록(FR-03) · `/tickets` 내 티켓(내리기, 교환 조건 진입)
  - `/tickets/:ticketId/exchange` 교환 희망 조건 폼 — 범위 카드(구역·열·번 범위 + **카드마다 추가금 4유형 라디오**, 카드 복제, 겹치는 범위의 추가금이 다르면 클라이언트 경고·서버 422 `WANT_EXTRA_CONFLICT`), 요청 단위 희망 회차 우선순위, 총 N석 합집합 미리보기와 5,000석·50범위 경고
  - `/exchange/requests/:requestId/candidates` 후보 목록·제안하기(신뢰도 없음, 참고용 금액 구간)에 '내 조건/상대 조건' 표시
  - `/exchange/matches` 내 매칭(보낸/받은 탭; 2026-10-10 `feature/exchange-reserve`에서 예약 UI 구현 완료, 미커밋). RESERVED 배지는 '예약 중', CHATTING은 '진행 중' 유지. CHATTING 카드: '예약하기'(한 명이 누르면 즉시 예약, 두 티켓 잠금)·받은 쪽 '거절'·'채팅 종료'(구 '취소' 라벨). RESERVED 카드: '내가/○○님이 예약했어요'·'예약 취소'(2단계 확인, 취소하면 매칭 상태로 복귀)·**'교환 수락' 버튼(보이되 비활성 aria-disabled, 준비 중 안내; 기존 '교환 완료' 버튼의 이름 변경, 상태·이력 라벨은 '교환 완료' 유지)**·예약 중에는 '거절'·'채팅 종료'도 숨기지 않고 비활성(aria-disabled, 사유 '먼저 예약을 취소해주세요' 안내). '동의 현황' 2줄과 '이 사람과 교환할게요' 버튼은 제거됐다. 응답 필드 `reservedBy`("ME"|"COUNTERPART"|null)·`reservedAt`·`myAccepted`/`counterpartAccepted`(항상 false). 후보 목록의 안내 문구도 새 예약 방식으로 정정했으나 후보 카드 '예약 중' 뱃지(Q-1, R1-1)는 미구현. 채팅·교환 완료는 '준비 중'(교환 완료 시 기존 티켓은 '교환됨', 새 자리 새 티켓이 생기는 모델 — `feature/exchange-complete`에서 구현 예정). 삭제된 요청의 매칭은 회색 '(삭제)', 내 조건이 삭제된 경우 '(내 조건 삭제됨)' 표시 (2026-10-09 7차 답변: 범위별 추가금·요청 소프트 삭제, 백엔드 V6·V7)
  - 헤더에 '내 티켓'·'내 매칭', 마이페이지 링크, 공연 상세에 '이 공연 티켓 등록' 버튼
  - 정한 항목: 열 끝·번 끝을 비우면 시작값으로 채워 전송, 상한은 하드코딩(서버 count/limit 우선), 마감 회차는 선택 불가
  - 알려진 한계: 브라우저 수동 점검·실서버 연동은 아직 하지 않았다.
- 좌석표 화면은 2026-10-07 방향 전환으로 삭제했다 (좌석표 코드는 태그 `archive/seatmap-track-20261007`에 보관).

- 공연 등록 화면은 3단계(①티켓팅 링크 ②공연 정보: 제목·공연장 이름(텍스트)·회차 ③확인·등록)다. 공연장 검색·VenuePicker는 삭제됐고 공연은 등록 후 수정·삭제할 수 없고(상세 화면 읽기 전용) 변경은 추후 관리자 수정 제안으로만 한다. 후속: 관리자 페이지 추가. (로고 변경은 완료)
